> 版本：v2（整合导航 / 论坛 / 收藏 / 关于 / 聊天 / 文件中转，账号以 localStorage 占位，后端待接入）
> 状态：需求稿（对齐已实现的单文件 Demo v2）

## 1. 产品概述

一个"网址导航 + 论坛"二合一的前端 Web 应用，面向个人/小圈子用户：

- **导航页**：个人常用站点、快捷访问、分类管理
- **论坛**：发帖、回帖、浏览与点赞
- **收藏**：个人收藏夹，收藏站点与帖子
- **关于**：项目介绍
- **聊天**：实时房间聊天（对应文件往返、在线协作）
- **文件中转**：密钥房间配对 + 文本粘贴 + 小文件直传

单文件 HTML Demo（v1→v2）已验证以上六个视图的完整交互流程；账号体系当前使用 localStorage 做前端占位，真后端（部署于香港 200M 服务器）接入后将切到 JWT 鉴权。

## 3. 视觉规范（硬性要求，不可妥协）

以下三项为视觉硬性要求，任何改版必须保留：

1. **光影**：背景光晕、卡片投射光、渐变高光
2. **玻璃拟态（Glassmorphism）**：半透明磨砂卡片、backdrop-blur、细描边
3. **指针阴影**：鼠标移动时卡片阴影跟随指针（tilt/glare 效果），悬停明显、平滑过渡

辅助规范：
- 色板：深色为主（玻璃质感更明显），品牌色建议 1 主色 + 1 强调色
- 圆角：卡片 12–16px；描边：1px 半透明白边
- 动效：阴影 / 位移 150–250ms ease；页面切换淡入即可，不做重动画
- 字体：系统字体栈，中文优先 PingFang SC / Microsoft YaHei

### 4.2 论坛视图

- 数据：`posts[]`、`replies[]`

### 4.3 收藏视图
- 收藏列表：站点收藏 + 帖子收藏，分 Tab 两类

### 4.4 关于视图

### 4.5 聊天视图

### 4.6 文件中转视图

- 会话按房间码维度持久化（localStorage 占位；接入后端后改为服务端消息）

- 目标：注册 / 登录 / JWT / 会话保持 / 退出

## 5. 前端状态管理与交互约定

- **状态方案**：当前 Demo 用原生 JS + localStorage；正式版建议 Vue3（Pinia）或 React（Zustand），二选一
- **认证**：`Authorization: Bearer <token>` 请求头；401 统一跳登录
- **实时通信**：聊天 / 中转房间用 WebSocket；断线重连 + 心跳
- **API 契约**：REST JSON；错误统一 `{ code, message }` 结构
- **未读红点**：通过 WS 推送或轮询拉取未读数驱动 transferBell

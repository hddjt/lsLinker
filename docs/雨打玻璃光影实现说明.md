# 雨打玻璃「光影」实现说明

> 动态效果中的「雨打玻璃」（type: `glass-rain`）本质是一个 **WebGL2 全屏叠层**。
> 项目侧只负责承载 canvas 和透传参数，真正出光影的是一套多 Pass 的着色器管线，核心在
> npm 包 `raindrop-fx` 的 `compose.glsl` 中。

---

## 1. 整体架构

```
┌─────────────────────────────────────────────────────────────┐
│  RainGlass.vue（项目侧）                                      │
│   · 全屏透明 <canvas>，opacity 0.64 + saturate/contrast 滤镜  │
│   · 传参：refractBase/refractScale/raindropCompose/mist...   │
└──────────────────────────┬──────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────┐
│  raindrop-fx（npm 包，WebGL2）                                │
│  ┌────────────┐   ┌────────────┐   ┌────────────────────┐   │
│  │ simulator  │   │ renderer   │   │  shader/           │   │
│  │ 雨滴物理     │→  │ 多 Pass 渲染 │→  │  compose.glsl 等   │   │
│  └────────────┘   └────────────┘   └────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
```

- **项目侧**：`front/src/components/RainGlass.vue`
- **渲染包**：`front/node_modules/raindrop-fx`（基于 `@sardinefish/zogra-renderer` 的 WebGL2 渲染器）

---

## 2. 光影实现原理（一句话）

> **背景先高斯模糊 → 雨滴贴图当「法线/高度图」→ 折射偏移 UV 采样虚化背景 →
> Lambertian 加背光阴影 + Blinn-Phong 加高光**，三者合成出「雨珠折射光线 + 背光阴影 + 顶部高光」的玻璃质感。

---

## 3. 三个关键要素

### 3.1 数据源头：把雨滴贴图当成「高度图」

`raindrop.png`（`raindrop-fx/assets/img/raindrop.png`）是一张**灰度渐变**贴图（上亮下暗），它同时充当两种角色：

1. **高度/斜率**：`renderer.ts` 中 `drawRaindrops()` 把每一滴雨用特殊混合模式写进 `raindropComposeTex` 的 `RG` 通道，于是 `compose.xy - 0.5` 就代表了水滴表面的坡度方向。
2. **伪法线**：`compose.glsl:36` 从坡度反推法线：
   ```glsl
   vec3 normal = normalize(vec3((compose.xy - vec2(0.5)) * vec2(2), 1.0));
   ```

### 3.2 折射（玻璃感） —— `compose.glsl:35`

```glsl
vec2 uv = vUV.xy + -(compose.xy - vec2(0.5)) * vec2(compose.b * uRefractParams.y + uRefractParams.x);
```

- 背景 UV 被水滴坡度**反向偏移**，形成「凸透镜」式的放大/折射效果；
- 采样对象是 `blurryBackground` —— 背景先被 `blur.glsl`（4 点盒式模糊 + 降/升采样）模糊，所以水滴里看到的背景是"透过玻璃"的**虚化像**；
- 折射强度由 `refractBase`（基础强度）与 `refractScale`（随水滴大小缩放）控制。

### 3.3 漫反射阴影（暗部） —— `compose.glsl:48`

```glsl
vec3 diffuse = vec3((lambertian - uDiffuseColor.a) * uDiffuseColor.rgb);
```

- `lambertian = clamp(dot(normalize(lightDir), normal), 0.0, 1.0)`；
- `uDiffuseColor.a` 即 `raindropShadowOffset`（默认 0.8），Lambertian 点积低于该阈值的区域变暗，形成水滴**背光侧的投影**（相当于 AO/暗边）。

### 3.4 Blinn-Phong 高光（亮斑） —— `compose.glsl:43,51`

```glsl
float blinnPhon = pow(max(dot(normal, halfDir), 0.0), uSpecularParams.a); // 默认 shininess=256
color.rgb += vec3(blinnPhon) * uSpecularParams.rgb;
```

- 光照方向 `uLightPos`（默认 `[-1, 1, 2, 0]`，即从屏幕右上方向照来）；
- 高指数（256）使高光集中在雨滴顶部的一小条亮斑，强化"水珠反光"。

## 4. 渲染管线（多 Pass，`renderer.ts`）

`RaindropRenderer.render()` 每帧执行：

| 顺序 | Pass | 作用 |
| --- | --- | --- |
| 1 | `drawDroplet()` | 生成细小水雾滴（可选） |
| 2 | `drawMist()` | 生成雾化层（项目已关闭） |
| 3 | `drawRaindrops()` | 把雨滴写入 `raindropComposeTex`（高度/法线缓冲） |
| 4 | `drawBackground()` | 画模糊后的背景 |
| 5 | `FinalCompose` | 用 `compose.glsl` 把「模糊背景 + 高度图」合成最终画面 |

关键细节：

- **`raindropCompose: 'smoother'`**：雨滴高度图使用
  `[OneMinusDstColor, OneMinusSrcColor]` 混合模式叠加（renderer.ts:440），
  雨水汇聚处坡度更陡、光影更明显，视觉上像"水珠互相融合"。
- **背景模糊**：`blurBackground()` 通过降采样再升采样的方式做高斯近似（blur.ts），
  步数由 `backgroundBlurSteps` 控制（项目设为 3）。

## 5. 项目侧参数（`RainGlass.vue`）

| 参数 | 项目取值 | 说明 |
| --- | --- | --- |
| `refractBase` | `0.35` | 折射基础强度 |
| `refractScale` | `0.65` | 折射随雨滴大小的缩放 |
| `raindropCompose` | `'smoother'` | 雨滴融合混合模式 |
| `backgroundBlurSteps` | `3`（移动端 2） | 背景模糊步数 |
| `mist` | `false` | 关闭包自带雾化层，避免整体发灰 |
| 背景图 | `/images/Shin&Rena.webp` | 预先 `decode` 后传给包，保证折射采样与 CSS 底图一致 |
| CSS | `opacity: 0.64; filter: saturate(1.16) contrast(1.04)` | 最终叠加在底图上的视觉微调 |

> 参数可在 `front/src/config/effects.config.js` 的 `glass-rain`（id: 6）中覆盖，
> 会通过 `props.config` 透传给 `RainGlass`。

## 6. 常见问题

- **为什么雨珠里能看到模糊的背景？**
  因为折射采样的是经过高斯模糊的 `blurryBackground`，玻璃 = 模糊背景 + UV 偏移。

- **光影从哪里来？**
  雨滴贴图自身的灰度渐变编码了"坡度"，坡度反推法线后，用 Lambertian 算阴影、用
  Blinn-Phong 算高光——**不需要额外的光照贴图**。

- **为什么关闭雾化（mist: false）？**
  包自带的雾化层会把整体压暗/发灰，项目保留自己的 CSS 背景遮罩，因此关掉它以免叠加变脏。
